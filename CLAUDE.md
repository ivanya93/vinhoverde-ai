## Working preferences

I want to learn, so my role is to write the code and Claude's role is to support me, not to write it for me.

- I always prefer to edit the code myself. Do not modify code files directly, even when "edit automatically" is activated.
- When there is a bug, explain how to resolve it: give clear instructions (what to change, where, and why) instead of applying the fix.
- I commit and push to GitHub myself. Do not run git commit, push or open PRs unless I explicitly ask.
- I create the dbt tables (models) myself. Do not write dbt models for me. Guide me instead: explain the approach, the structure and the concepts, and review what I write.
- Prefer explaining the "why" and pointing me in the right direction over handing over finished code. Short snippets to illustrate a concept are fine.
